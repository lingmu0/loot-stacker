# Loot Stacker 1.0.0a — NeoForge 26.1.2

- Add support for Minecraft 26.1.2 on NeoForge 26.1.2.107 or newer 26.1.2 builds. Requires Java 25.
- Merge matching stackable loot items and their data components before placing them into a container, preserving space for subsequent loot.
- Automatically disable Loot Stacker's mixin when PackCoreMod (`scholarofcrimson`) is loaded.
- Keep both development loot tables out of the release JAR.

Install on the server for multiplayer; clients do not need the mod. Single-player requires installation on the client because it runs the integrated server.
